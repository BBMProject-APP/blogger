# 🎬 Animation Content Feeder Automation

Bot otomatis berbasis Python dan Gemini AI yang mencari tutorial serta berita teknologi animasi terbaru, menyimpannya ke `animation_data.json`, dan mengirimkan laporan lengkap via Email.

## 📁 Struktur Direktori

```text
.
├── .github/
│   └── workflows/
│       └── autofeeder.yml   # Workflow GitHub Actions
├── animation_feeder.py       # Script Python utama
├── requirements.txt         # Dependencies Python
└── README.md
```
